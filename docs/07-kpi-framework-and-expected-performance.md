# 07 - Campaign KPI Framework & Expected Performance

## KPI framework

| KPI | Definition | Source | 30-day target | Review |
|---|---|---|---|---|
| Website visits | Sessions to vedatechnology.in from all organic sources | Google Analytics (GA4) | See expected scenario | Weekly |
| Apply-page visits | Sessions that reach the apply page | GA4 | See expected scenario | Weekly |
| Internship applications | Completed apply-form submissions | GA4 event / form data | See expected scenario | Weekly |
| Service inquiries | Quote-form submissions + WhatsApp/email inquiries | GA4 event + inbox log | See expected scenario | Weekly |
| Engagement rate | (Reactions + comments + shares + saves) / impressions | LinkedIn & Instagram insights | 4-5% | Per post |
| Follower growth | Net new followers on LinkedIn + Instagram | Platform insights | +10% in 30 days | Weekly |
| Link click-through rate | Link clicks / impressions | Platform insights + UTM | 1-2% | Per post |
| Visit-to-application rate | Applications / apply-page visits | GA4 | 8-10% | Weekly |
| Organic search clicks | Clicks from Google Search | Google Search Console | See expected scenario | Weekly |
| Lead-magnet downloads | Checklist / roadmap form submissions | Google Form | 40-60 | Weekly |

### Reading the numbers

- These are planning estimates for a new organic campaign, not guarantees. The formulas are live in `data/Veda_Campaign_Workbook.xlsx` (sheet *Expected Performance*) - change any assumption and every result updates.
- Biggest levers: average impressions per LinkedIn post (helped by intern reshares) and the apply-page conversion rate (helped by the trust fixes in doc 03).
- Service inquiries stay low in 30 days on purpose: B2B buying cycles are longer, so this campaign builds the pages and trust that convert later.
- Review weekly: if a format beats the average by 2x, give it more slots in weeks 3-4.
