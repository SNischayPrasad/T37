# 03 - SEO Content Opportunities & Website Recommendations

## SEO content opportunities

| Opportunity | What and why |
|---|---|
| One landing page per internship track | Title, syllabus by level, sample tasks, FAQ (FAQPage schema), Apply CTA. Targets every 'Tracks' keyword. |
| Certificate verification guide | 'How to verify a Veda Technology certificate' - answers a trust query and supports recruiters. |
| Blog: Internships for 2nd-year B.Tech students | Practical guide; links to Level 1 tracks. |
| Blog: Is a virtual internship worth it? | Honest pros/cons and what recruiters check; reduces scam fear. |
| Blog: Portfolio project ideas by domain | Evergreen, shareable; internal links to each track page. |
| Intern project showcase page | Curated intern work (with consent) - fresh content + social proof. |
| Separate service pages | Web, App, Cloud, Data Science, Digital Marketing - each with process, FAQ and quote form. |
| Local SEO | Google Business Profile + 'website development in Bihar / Lakhisarai' page with NAP details. |

## Website content recommendations

| Recommendation | Details |
|---|---|
| Fix the homepage counters | The public page text shows '0+ Interns Trained', '0+ Hiring Partners' (JavaScript counters). Render real, verified numbers in HTML - or remove them - so crawlers and slow connections don't see zeros. |
| Give each service its own URL | The chat widget links every service to /#services. Dedicated pages rank better and can be tracked separately. |
| Add a 'How it works' timeline | Apply -> Offer letter (1st/15th) -> Dashboard -> Daily tasks -> Mentor review -> Certificate + LOR. |
| Show the trust signals together | MSME/Udyam registration, certificate verification ID, free application - one trust strip above the fold. |
| Make testimonials verifiable | Name, track, and LinkedIn link (with consent) instead of anonymous quotes. |
| Add a short service-quote form | Name, business, service needed, budget range, WhatsApp number - with clear response-time expectation. |
| Technical SEO basics | Search Console verification, XML sitemap, Organization + FAQPage + Course schema, image alt text, Core Web Vitals check. |
| Analytics events | GA4 events for apply_click, apply_submit, quote_submit, whatsapp_click; UTM links on every social post. |

## Search Console & Analytics concepts used

- Search Console: impressions, clicks, CTR and average position per query - used to find keywords where Veda ranks on page 2 and can be pushed up with better content.
- Search Console: Coverage/Pages report and sitemap submission to confirm all track and service pages are indexed.
- Analytics (GA4): traffic acquisition by source/medium (UTM), key events (apply_submit, quote_submit), and funnel exploration from landing page to application.
